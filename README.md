# 📅 Application de Pointage avec Prédiction des Absences

## 🖥️ Description

Cette application desktop permet de gérer le **pointage des employés** dans une entreprise tout en intégrant un **modèle prédictif** d’absences basé sur des données historiques.

Développée en **Python** avec **PyQt** pour l’interface graphique et **MySQL** pour la base de données, l'application inclut un module **TensorFlow** pour prédire les absences potentielles à partir de facteurs comme l’historique de présence, les congés, ou les jours fériés.

---

## 🛠️ Technologies Utilisées

- 🐍 **Python 3.8+**
- 🖼️ **PyQt5/PyQt6** — Interface graphique
- 🗄️ **MySQL** — Base de données relationnelle
- 🤖 **TensorFlow / Keras** — Prédiction d’absences avec modèle de Machine Learning
- 📊 **Pandas / NumPy** — Prétraitement des données
- 🧪 **scikit-learn** — Évaluation et préparation des données
